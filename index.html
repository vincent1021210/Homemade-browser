自製瀏覽器

Windows 上的桌面瀏覽器外殼。分頁、網址列、書籤與瀏覽紀錄是這個專案寫的；網頁的排版、JavaScript 與影片交給 Qt WebEngine。

原始碼 下載 main

在這台 Windows 上執行

  1. 安裝 Python 3.12，並確認命令列可以執行 python。
  2. 雙擊 安裝.bat。第一次會下載 Qt WebEngine，需要幾分鐘。
  3. 雙擊 啟動瀏覽器.bat。

這個程式負責什麼

  • 分頁、上一頁、下一頁、重新載入與首頁
  • 網址列：網址直接開啟，其餘文字用 Google 搜尋
  • 書籤、最近瀏覽，以及重新開啟上次的分頁
  • 下載檔案、網站權限詢問、頁面內尋找與縮放

快捷鍵

按鍵作用
Ctrl+T新分頁
Ctrl+W關閉分頁
Ctrl+L選取網址列
Ctrl+D加入或移除書籤
Ctrl+F在頁面中尋找
Alt+← / Alt+→上一頁 / 下一頁
